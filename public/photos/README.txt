WILLSON'S ORIGINAL PHOTOS — drop them in this folder, unmodified.

The site automatically prefers these files and uses them exactly as-is.
The bundled stand-in images are only shown when a file below is missing
(or invalid/corrupted).

  pouring.png   → the black-gloves latte pour with the rainbow pitcher (homepage portrait)
  cup.png       → the tulip latte in the glass cup on the granite counter (About section)
  portrait.jpg  → the full-length photo in the heritage room ("Pour with a pro" card)

Keep the filenames exactly as above, including the extension shown — the
site loads the file by exact name. If your photo is actually a PNG,
save it as .png; if it's a real JPG, save it as .jpg. Renaming a PNG to
.jpg (or vice versa) without re-exporting it will break the image.
